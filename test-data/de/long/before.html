Erste Schritte

Die Einrichtung von Notebook Online dauert etwa fünf Minuten:

  1. Erstellen Sie ein Konto unter example.com/signup.
  2. Bestätigen Sie Ihre E-Mail-Adresse. Der Link ist 24 Stunden gültig.
  3. Installieren Sie die App auf Ihren Geräten:
    • Windows und macOS: Laden Sie sie von unserer Website herunter;
    • Android und iOS: Laden Sie sie aus dem App-Store Ihres Telefons.
  4. Melden Sie sich an und erstellen Sie Ihr erstes Notizbuch.

Wenn Sie so weit sind, fahren Sie mit diesen Schritten fort:

  1. Importieren Sie Notizen aus einer anderen App.
  2. Laden Sie Personen zu einem geteilten Notizbuch ein.

Tipp 💡 Heften Sie die Notizen, die Sie am häufigsten nutzen, oben in der Liste an.

Was Sie in einem Notizbuch aufbewahren können

  • Textnotizen mit Formatierung,
  • Checklisten,
  • Bilder und PDF-Dateien bis 25 MB,
  • im Browser gespeicherte Webseiten.

Beispiel-Checkliste

Notizen freigeben

Sie können eine einzelne Notiz oder ein ganzes Notizbuch freigeben. Öffnen Sie die Notiz, klicken Sie auf Freigeben und geben Sie die E-Mail-Adressen der Personen ein, die Sie einladen möchten.

Rollen

  • Leser – kann Notizen lesen.
  • Kommentator – kann Notizen lesen und kommentieren.
  • Bearbeiter – kann Notizen ändern und andere einladen.

Mehr dazu in der Anleitung zum Freigeben, oder fragen Sie den Support.

Über öffentliche Links kann jeder mit dem Link die Notiz ohne Anmeldung lesen. Sie können sie jederzeit in den Einstellungen der Notiz deaktivieren.

Formatierung

Notizen unterstützen Fett, Kursiv, Unterstrichen, Durchgestrichen, Hervorhebung, Inline-Code, Tiefgestellt und Hochgestellt, sodass Sie H2O oder 103 schreiben können.

Wichtig: Aus anderen Apps kopierte Formatierung bleibt beim Einfügen erhalten.

Zentrierter Text eignet sich gut für Titel und Zitate.

Text kann eine Farbe oder einen Hintergrund haben.

Nachverfolgte Änderungen aus anderen Editoren bleiben ebenfalls erhalten: alte Formulierung neue Formulierung.

Drücken Sie Umschalt + Eingabe, um eine neue Zeile ohne neuen Absatz zu beginnen:
erste Zeile
zweite Zeile

// Codeblöcke behalten ihre Abstände
function shortName(name) {
  if (name.length < 10) {
    return name;
  }
  return name.slice(0, 9) + '…';
}

Datenschutz und Daten

Ihre Notizen werden bei der Übertragung und im Ruhezustand verschlüsselt.1 Wir verkaufen Ihre Daten nie und zeigen keine Werbung.

Sie können alle Notizen als HTML- oder Markdown-Dateien exportieren oder Ihr Konto unter Einstellungen → Konto löschen. Gelöschte Konten werden nach 30 Tagen aus den Sicherungen entfernt.
