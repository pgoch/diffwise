So ordnen Sie Ihre Notizen

Eine gute Struktur hilft Ihnen, jede Notiz in Sekunden zu finden. Dieser Artikel zeigt vier Wege, Notizen in Notebook Online zu ordnen: Notizbücher, Stapel, Tags und angeheftete Notizen.

Notizbücher

Notizbücher fassen zusammengehörige Notizen zusammen, zum Beispiel Arbeit, Zuhause oder Rezepte. Jede Notiz gehört zu genau einem Notizbuch.

Um ein Notizbuch anzulegen, klicken Sie oben in der Seitenleiste auf Neues Notizbuch und geben ihm einen Namen.

Stapel

Stapel fassen Notizbücher zusammen. Sie helfen, wenn Sie mehr als zehn Notizbücher haben.

Tags

Tags gelten für alle Notizbücher. Eine Notiz kann bis zu 50 Tags haben, und Sie können die Liste nach mehreren Tags gleichzeitig filtern.

  • Verwenden Sie kurze, kleingeschriebene Namen wie rechnung oder ideen.
  • Prüfen Sie Ihre Tags einmal im Monat und führen Sie doppelte zusammen.
  • Benennen Sie alle Tags in einer Sprache.

Angeheftete Notizen

Heften Sie die Notizen an, die Sie jeden Tag öffnen.

Schritt für Schritt: Notizen aufräumen

  1. Legen Sie für jeden Lebensbereich ein Notizbuch an.
  2. Verschieben Sie vorhandene Notizen in die passenden Notizbücher.
  3. Versehen Sie Notizen, nach denen Sie oft suchen, mit Tags.
  4. Löschen Sie Notizen, die Sie nicht mehr brauchen.
  5. Heften Sie bis zu zehn Notizen an.

Tipp: Sie müssen nicht alles auf einmal erledigen. Beginnen Sie mit den Notizen der letzten Woche.

Häufige Fragen

Kann eine Notiz in zwei Notizbüchern sein?

Nein. Verwenden Sie stattdessen ein Tag oder fügen Sie einen Link zur Notiz hinzu.

Gibt es eine Grenze für Notizbücher?

Mit dem Tarif Kostenlos sind 10 Notizbücher möglich. Bezahlte Tarife haben keine Grenze.

Was passiert mit Tags, wenn ich ein Notizbuch lösche?

Tags bleiben erhalten. Sie verschwinden erst, wenn keine Notiz sie mehr verwendet.
