So ordnen Sie Ihre Notizen

Eine gute Struktur hilft Ihnen, jede Notiz in Sekunden zu finden. Dieser Artikel zeigt drei Wege, Notizen in Notebook Online zu ordnen: Notizbücher, Tags und angeheftete Notizen.

Notizbücher

Notizbücher fassen zusammengehörige Notizen zusammen, zum Beispiel Arbeit, Zuhause oder Reisen. Jede Notiz gehört zu genau einem Notizbuch.

Um ein Notizbuch anzulegen, klicken Sie in der Seitenleiste auf Neues Notizbuch und geben ihm einen Namen. Den Namen können Sie später ändern.

Tags

Tags gelten für alle Notizbücher. Eine Notiz kann bis zu 20 Tags haben, und Sie können die Liste nach mehreren Tags gleichzeitig filtern.

  • Verwenden Sie kurze, kleingeschriebene Namen wie rechnung oder ideen.
  • Vermeiden Sie Tags, die den Namen eines Notizbuchs wiederholen.
  • Prüfen Sie Ihre Tags einmal im Monat und führen Sie doppelte zusammen.

Angeheftete Notizen

Heften Sie die Notizen an, die Sie jeden Tag öffnen. Angeheftete Notizen stehen in jedem Notizbuch immer oben in der Liste.

Schritt für Schritt: Notizen aufräumen

  1. Legen Sie für jeden Lebensbereich ein Notizbuch an.
  2. Verschieben Sie vorhandene Notizen in die passenden Notizbücher.
  3. Versehen Sie Notizen, nach denen Sie oft suchen, mit Tags.
  4. Heften Sie bis zu fünf Notizen an.

Tipp: Sie müssen nicht alles auf einmal erledigen. Beginnen Sie mit den Notizen des letzten Monats.

Häufige Fragen

Kann eine Notiz in zwei Notizbüchern sein?

Nein. Verwenden Sie stattdessen ein Tag oder fügen Sie einen Link zur Notiz hinzu.

Was passiert mit Tags, wenn ich ein Notizbuch lösche?

Tags bleiben erhalten. Sie verschwinden erst, wenn keine Notiz sie mehr verwendet.

Gibt es eine Grenze für Notizbücher?

Mit dem Tarif Kostenlos sind 10 Notizbücher möglich. Bezahlte Tarife haben keine Grenze.
