はじめに

Notebook Online は、次の手順で 5 分ほどで設定できます。

  1. example.com/signup でアカウントを作成します。
  2. メールアドレスを確認します。リンクの有効期限は 24 時間です。
  3. お使いのデバイスにアプリをインストールします。
    • Windows と macOS：当社のウェブサイトからダウンロードします。
    • Android と iOS：スマートフォンのアプリストアから入手します。
  4. サインインして、最初のノートブックを作成します。

準備ができたら、次の手順に進みます。

  1. ほかのアプリからノートをインポートします。
  2. 共有ノートブックにメンバーを招待します。

ヒント 💡 よく使うノートは一覧の先頭にピン留めしましょう。

ノートブックに保存できるもの

  • チェックリスト
  • 25 MB までの画像と PDF ファイル
  • ブラウザーから保存したウェブページ

ノートの共有

1 つのノートだけを共有することも、ノートブック全体を共有することもできます。ノートを開き、 共有をクリックして、招待する相手のメールアドレスを入力します。

役割

  • 閲覧者：ノートを閲覧できます。
  • コメント投稿者：ノートを閲覧し、コメントを追加できます。
  • 編集者：ノートを変更し、ほかのユーザーを招待できます。

詳しくは共有ガイドをご覧いただくか、サポートにお問い合わせください。

公開リンクを使うと、リンクを知っている人なら誰でもサインインせずにノートを閲覧できます。公開リンクはノートの設定からいつでもオフにできます。

書式設定

ノートでは、太字、斜体、下線、取り消し線、蛍光ペン、インライン コード、下付き文字、上付き文字を使えるので、H2O や 103 のように書けます。

重要：ほかのアプリからコピーした書式は、貼り付けても保持されます。

中央揃えのテキストは、タイトルや引用に向いています。

テキストには 色 や 背景色 を設定できます。

ほかのエディターの変更履歴も保持されます：以前の表現 新しい表現。

段落を変えずに改行するには、Shift + Enter を押します。

プライバシーとデータ

ノートは転送時も保存時も暗号化されます。1お客様のデータを販売したり、広告を表示したりすることはありません。

すべてのノートを HTML または Markdown ファイルとしてエクスポートしたり、設定 → アカウントでアカウントを削除したりできます。削除したアカウントは 30 日後にバックアップから消去されます。

サーバーはどこにありますか？

サーバーはフランクフルトとアムステルダムのデータセンターにあります。
